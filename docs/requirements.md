# Requirements Traceability Matrix &bull; University Learning &amp; Internship Platform

This document maps the project implementation directly against the **Project 4: University Learning &amp; Internship Platform** technical brief. It provides full transparency regarding functional and non-functional requirements, identifying whether each capability is **Implemented**, **Partial**, or **Not Implemented**, along with the exact tests and UI components that verify it.

---

## 3. Summary of Gaps &amp; Out-of-Scope Items

In strict adherence to the project guidelines, no unrequested features were implemented. The following capabilities identified in generalized project briefs remain out of scope for v1.0.0:

1. **In-App Notification Center**: No persistent message table or bell icon inbox.
2. **Badges &amp; Leaderboards**: No gamified point systems or digital badges.
3. **Rich Learning Resources**: File/PDF uploads for courses were not implemented; structured text syllabi are used.
4. **AI Resume &amp; Job Matching**: No machine learning or LLM integrations; matching uses exact SQL filters.
5. **Emailed Password Reset**: External SMTP integration is omitted; administrative password reset is supported.
6. **Docker Engine**: Deferred due to local host daemon availability; native developer automation is supported.
