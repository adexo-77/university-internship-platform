# Requirements Traceability Matrix &bull; University Learning &amp; Internship Platform

## 3. Summary of Gaps &amp; Out-of-Scope Items

In strict adherence to the project guidelines, no unrequested features were implemented. The following capabilities identified in generalized project briefs remain out of scope for v1.1.0:

1. **External Notification Channels**: Push notifications, SMS messaging, and external email dispatches are omitted; in-app notification center is fully implemented.
2. **Badges &amp; Leaderboards**: No gamified point systems or digital badges.
3. **Binary File Uploads**: Direct binary file uploads (PDF slides, lecture videos, downloadable archives) are not implemented; course resources are delivered as validated external HTTP/HTTPS links and structured text syllabi.
4. **AI Resume &amp; Job Matching**: No machine learning, LLM integrations, or algorithmic scoring; only keyword search and a work-mode filter exist.
5. **Emailed Password Reset**: External SMTP integration is omitted; administrative password reset is supported.
